# v134 — Ảnh duyệt giao diện

Ảnh chụp từ giao diện WPF thực tế, chưa phát hành lên kênh cập nhật.
Giữ vòng trong, hạ viền ngoài và vạch chia xuống chung đáy; kim là thanh thẳng bo góc, nền vòng trong sáng nhẹ từ đáy và mờ lên trên.
Có ảnh 180 km/h và 200 km/h; STEP nhỏ không nhân đôi mật độ vạch.

Kênh cập nhật hiện vẫn là v133.
