# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức. Source code giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.72

NGẮT KẾT NỐI thủ công giữ nguyên cửa sổ chart và active; chỉ dừng phiên kết nối phần cứng. Kết nối lại đồng bộ BIT CHART ON sau status hợp lệ, giữ các bit khác. Nút X/BIT OFF đã xác nhận vẫn đóng chart; thoát ứng dụng vẫn đóng cửa sổ phụ. Giữ ba trạng thái kết nối tiếng Việt, dữ liệu và các sửa từ v171.

Bản phát hành đã qua kiểm tra Windows, quét Defender cho ứng dụng và bộ cập nhật, kiểm tra giữ JSON/RUN và khởi động lại.

Trong SETTINGS, bấm ↻ để kiểm tra rồi chọn CẬP NHẬT.
