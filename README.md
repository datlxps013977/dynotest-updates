# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức. Source code được giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.26

- Giao diện nền tối, viền mảnh; bỏ phát sáng ở viền các cửa sổ.
- Đồng hồ chỉ giữ nền dải vạch chia và vòng trong chứa số; bỏ lớp nền phủ cả mặt.
- Thu nhỏ và hạ chữ RPM/SPEED; tăng vòng trong, số dài tự vừa vòng.
- Thêm nét vòng mảnh ngoài vạch chia, vạch TORQUE cùng màu cam.
- Checkbox HP / TOQ / AFR căn đều, ghi AFR tự bật biểu đồ AFR.
- Dùng chung lưới Dyno và khôi phục hover AFR, giảm vạch chia; đổi AFR TARGET cập nhật đường mục tiêu.
- Menu active chỉ đổi chữ và icon sang cyan.
- Bản dựng từ nền xử lý v122. Giữ cấu hình JSON và dữ liệu RUN; chỉ thay file chương trình có thay đổi và tự mở lại.

Trong SETTINGS, bấm ↻ cạnh nút cập nhật để kiểm tra ngay, rồi chọn CẬP NHẬT và xem chi tiết trước khi xác nhận. Ứng dụng cũng kiểm tra một lần khi mở.

[Tải bộ cập nhật v126](releases/v126/Dynotest_Update.exe) · [SHA-256](releases/v126/SHA256.txt) · [Kiểm tra giữ JSON/RUN và khởi động lại](releases/v126/update-checks.txt).

Gói phát hành đã qua quét Microsoft Defender trên Windows với bộ nhận diện được ghi lại trong kiểm tra phát hành. Kết quả quét không phải bảo đảm tuyệt đối về an toàn.

Bản v123 cũ đã rút khỏi kênh cập nhật. Đây là bản dựng lại từ v122; source luôn giữ riêng tư.
