# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức. Source code được giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.27

- Hover AFR cùng màu đường RUN; icon AFR; lưới AFR còn 4 đường ngang.
- Nền vòng trong rõ hơn, đuôi kim ngắn hơn, viền vạch chia dày hơn.
- OXYGEN hiện chữ/icon đỏ khi phần cứng đang bật; nút đo có hover rõ hơn.
- F1 đo công suất, F2 dừng đo, F3 ghi AFR, F4 ngừng ghi.
- MAX/DỪNG đợi đủ mẫu cho frame cuối rồi lưu. Hiển thị toàn bộ frame đã hoàn tất, không cắt theo MAX. RAW giữ mẫu đệm để mở lại cùng kết quả.
- Giữ nguyên JSON và RUN đã lưu; tự mở lại sau cập nhật.

Trong SETTINGS, bấm ↻ cạnh nút cập nhật để kiểm tra ngay, rồi chọn CẬP NHẬT và xem chi tiết trước khi xác nhận. Ứng dụng cũng kiểm tra một lần khi mở.

[Tải bộ cập nhật v127](releases/v127/Dynotest_Update.exe) · [SHA-256](releases/v127/SHA256.txt) · [Kiểm tra giữ JSON/RUN và khởi động lại](releases/v127/update-checks.txt).
