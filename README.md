# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức của DynoTest DATNL. Source code được giữ trong repo riêng tư.

Ứng dụng hỗ trợ cập nhật trực tuyến từ ver1.0.91. Mỗi lần mở ứng dụng, phần mềm kiểm tra `latest.xml` một lần. Nếu có bản mới, nút cập nhật trong Settings sáng lên. Chỉ tải khi người dùng bấm cập nhật.

File tải được kiểm tra kích thước, SHA-256 và phiên bản trước khi chạy. Bộ cập nhật chỉ thay các file chương trình đã thay đổi, giữ cấu hình JSON và RUN, rồi tự mở lại phần mềm.

Các bản cũ chưa hỗ trợ kiểm tra trực tuyến cần nâng lên ver1.0.91 một lần bằng file cập nhật.

## Tải bản hỗ trợ cập nhật trực tuyến lần đầu

- [Dynotest_Update.exe — ver1.0.91](https://raw.githubusercontent.com/datlxps013977/dynotest-updates/main/releases/v91/Dynotest_Update.exe)
- Nếu đang dùng v90, mở Settings → CHỌN FILE EXE → chọn file trên → cập nhật.
- Nếu chưa cài phần mềm, dùng bộ cài từ repo source riêng tư.
- Các bản mới hơn sẽ được báo ngay trong Settings sau khi mở lại phần mềm.
