# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức. Source code giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.77

Auto Tune bỏ nút mở riêng; bấm CHƯA BẬT PHẦN MỀM ECU khi phần mềm ECU tắt, mở đúng EXE/phiên bản trong nền và nối lại PID trên cùng cửa sổ. Giữ target/correction, khóa dữ liệu cũ/Execute khi mất phần mềm, chặn bấm trùng và phản hồi cũ. Viền nút KẾT NỐI xanh lá, NGẮT KẾT NỐI đỏ đồng bộ chữ/icon, giữ màu khi hover. Nền màn hình chính carbon tối dạng vector tĩnh. Giữ F3/F4/F5/F6, các sửa RUN_28 và dữ liệu JSON/RUN.

Bản phát hành đã qua kiểm tra Windows, quét Defender cho ứng dụng và bộ cập nhật, kiểm tra giữ JSON/RUN và khởi động lại.

Trong SETTINGS, bấm ↻ để kiểm tra rồi chọn CẬP NHẬT.
