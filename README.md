# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức. Source code giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.60

Khôi phục lưới cố định GEAR và đồng bộ số trục X/Y theo đúng vị trí lưới trên DYNO, AFR, CVT, GEAR, Giả lập và biểu đồ in. Giá trị thay đổi theo phạm vi dữ liệu/zoom/RUN, cho phép số lẻ. Cả hai trục Y cùng hàng lưới, AFR giữ 4 đường ngang. Không thay đổi dữ liệu hay công thức.

Bản phát hành đã qua kiểm tra Windows, quét Defender cho ứng dụng và bộ cập nhật, kiểm tra giữ JSON/RUN và khởi động lại.

Trong SETTINGS, bấm ↻ để kiểm tra rồi chọn CẬP NHẬT.
