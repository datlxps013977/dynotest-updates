# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức. Source code giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.67

Bốn ô MAX theo RUN vừa bật/chọn, không lấy số lớn nhất giữa nhiều RUN. Nhãn MAX HP/TQ trên chart dùng cùng MAX và tọa độ với các ô MAX và danh sách RUN. Bốn ô MAX live cập nhật từ preview đã xử lý, giữ đỉnh HP/TQ và RPM tương ứng khi thòng ga, reset theo lượt mới và không bị RUN cũ lớn hơn ghi đè. Dùng lại control/cache. AFR được áp nền ngay lúc tạo và trước mỗi render để tránh nền trắng khi mở/hiện/xóa. Giữ dữ liệu, smoothing và các thay đổi v166.

Bản phát hành đã qua kiểm tra Windows, quét Defender cho ứng dụng và bộ cập nhật, kiểm tra giữ JSON/RUN và khởi động lại.
