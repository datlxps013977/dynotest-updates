# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức. Source code giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.78

Header và footer dùng nền carbon đan chéo 45 độ, sợi nhỏ hơn phần giữa, cạnh sáng nhẹ và bóng chìm đen xanh. Phần giữa giữ nguyên carbon hiện tại; nền vector tĩnh, không thêm timer/ảnh ngoài. Giữ mở ECU từ trạng thái và viền nút kết nối đồng bộ màu. Bốn LED CPU/AFR/RPM/SPEED riêng màu giữa đồng hồ, theo gói dữ liệu phần cứng hợp lệ, giữ sáng ngắn và tắt khi ngừng nhận/ngắt kết nối. Giữ F3/F4/F5/F6, các sửa RUN_28 và dữ liệu JSON/RUN.

Bản phát hành đã qua kiểm tra Windows, quét Defender cho ứng dụng và bộ cập nhật, kiểm tra giữ JSON/RUN và khởi động lại.

Trong SETTINGS, bấm ↻ để kiểm tra rồi chọn CẬP NHẬT.
