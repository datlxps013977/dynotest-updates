# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức. Source code được giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.25

- Giao diện nền tối, viền mảnh; bỏ phát sáng ở viền các cửa sổ.
- Căn lại RPM/SPEED, đưa vạch chia sát vòng ngoài và thêm nền tối cho thang đo, vòng giữa.
- Chọn HP / TOQ / AFR trên Chart; ghi AFR tự bật biểu đồ AFR.
- Bản dựng từ nền xử lý v122. Giữ cấu hình JSON và dữ liệu RUN; chỉ thay file chương trình có thay đổi và tự mở lại.

Trong SETTINGS, bấm ↻ cạnh nút cập nhật để kiểm tra ngay, rồi chọn CẬP NHẬT và xem chi tiết trước khi xác nhận. Ứng dụng cũng kiểm tra một lần khi mở.

[Tải bộ cập nhật v125](releases/v125/Dynotest_Update.exe) · [SHA-256](releases/v125/SHA256.txt) · [Kiểm tra giữ JSON/RUN và khởi động lại](releases/v125/update-checks.txt).

Gói phát hành đã qua quét Microsoft Defender trên Windows với bộ nhận diện được ghi lại trong kiểm tra phát hành. Kết quả quét không phải bảo đảm tuyệt đối về an toàn.
