# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức. Source code giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.63

BẢNG RATIO bỏ logo, dùng header gọn và bỏ dải trắng ở mép trên; giữ khả năng kéo, đổi kích thước và đóng cửa sổ. TỈ SỐ CÁC CẤP chia cố định 6 cột trong khung bên trái. Mỗi ô giữ 1/6 chiều ngang, kể cả khi RUN chỉ có 1 số; các cấp có dữ liệu xếp từ trái sang phải, phần còn lại để trống. Bỏ tiêu đề dọc TỈ SỐ TRUYỀN/RPM của GEAR, giữ số trục và legend trên. Sửa hover/nhấn nút TÍNH TOÁN & CẬP NHẬT CHART trong Giả lập bằng trạng thái nền phẳng trong template. Giữ nguyên nội dung và dữ liệu.

Bản phát hành đã qua kiểm tra Windows, quét Defender cho ứng dụng và bộ cập nhật, kiểm tra giữ JSON/RUN và khởi động lại.

Trong SETTINGS, bấm ↻ để kiểm tra rồi chọn CẬP NHẬT.
