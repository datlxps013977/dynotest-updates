## Bản hiện tại: ver1.1.79

Đèn CPU/NGUỒN/REMOTE/AFR/RPM/SPEED nằm giữa hai đồng hồ, có nền box riêng. Các trạng thái cảm biến/remote/nguồn lấy từ gói BRT 1003. Nguồn hiện AC/ẮC QUY/--; AFR hiện AFR 1, AFR 2 hoặc AFR 1 + 2. Carbon rõ sợi hơn, đồng hồ giãn cân đối, viền cột trái rõ hơn; cảnh báo sai phiên bản Auto Tune rút gọn cạnh trạng thái ECU. Bỏ tooltip đèn.

Đóng gói từ EXE v1.1.79.0 do người dùng biên dịch và chạy trên Windows. Kiểm tra x86, DLL/config tương thích, manifest SHA-256 và bộ máy cập nhật trên .NET 8/Linux, gồm giữ JSON/RUN và khôi phục khi lỗi. Không chạy lại GitHub Actions, Defender hay kiểm tra khởi động lại Windows cho gói này.
