# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức. Source code được giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.28

- Giảm nhẹ số trên thang chia RPM/SPEED.
- Nền vòng trong RPM/SPEED mờ hơn; giữ nguyên viền và số đo.
- Bỏ viền mờ bên trong thẻ RUN active; giữ viền ngoài và vạch màu RUN.
- Thông báo bản mới cạnh ver ở chân cửa sổ chính; bấm để mở phần cập nhật trong SETTINGS.
- Hover AFR theo RPM hiển thị số nguyên.
- Giữ các chức năng v127, cấu hình JSON và RUN cũ; tự mở lại sau cập nhật.

Trong SETTINGS, bấm ↻ cạnh nút cập nhật để kiểm tra ngay, rồi chọn CẬP NHẬT và xem chi tiết trước khi xác nhận. Ứng dụng cũng kiểm tra một lần khi mở.

[Tải bộ cập nhật v128](releases/v128/Dynotest_Update.exe) · [SHA-256](releases/v128/SHA256.txt) · [Kiểm tra giữ JSON/RUN và khởi động lại](releases/v128/update-checks.txt).

Gói phát hành đã qua quét Microsoft Defender trên Windows với bộ nhận diện được ghi lại trong kiểm tra phát hành. Kết quả quét không phải bảo đảm tuyệt đối về an toàn.

Bản v123 cũ đã rút khỏi kênh cập nhật. Đây là bản dựng lại từ v122; source luôn giữ riêng tư.
