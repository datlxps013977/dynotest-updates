# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức. Source code giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.58

Sửa hàng trống cuối popup DATABASE XE. TỈ SỐ CÁC CẤP hiển thị từng ô màu theo mẫu, một ô cho mỗi cấp số nhận diện: số, tỉ số lớn, tốc độ và nhãn đánh giá. Rê chuột xem thêm tham chiếu, dải tốc độ và điểm đá số. Căn icon bánh răng đồng tâm. Giữ nguyên bộ nhận diện cấp số và công thức. Bỏ RPM biểu đồ AFR khỏi Settings/JSON; gỡ ba khóa cũ và lấy trục từ DYNO. Admin thêm khôi phục đồng thời hai JSON mẫu, sao lưu và dùng schema mặc định mới.

Bản phát hành đã qua kiểm tra Windows, quét Defender cho ứng dụng và bộ cập nhật, kiểm tra giữ JSON/RUN và khởi động lại.

Trong SETTINGS, bấm ↻ để kiểm tra rồi chọn CẬP NHẬT.
