# DynoTest DATNL — Updates

Kênh cập nhật chính thức. Source code giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.41

- Đồng bộ header DYNO, CVT, GEAR, GIẢ LẬP, AUTO TUNE và CARB theo cùng mẫu XAML.
- Logo bên trái, nền tối phẳng, nút chức năng chữ nhật bo nhẹ; vạch ngăn và nút thu nhỏ/phóng to/đóng màu trắng bên phải.
- Bỏ ảnh xe, họa tiết cũ và nút nghiêng. Giữ thông tin RUN, trạng thái ECU và chức năng từng nút.
- Header giữ chiều cao khi nội dung bên dưới co giãn; tự chừa chỗ cho logo và nút khi cửa sổ hẹp. Hộp thoại nhỏ và AFR có phiên bản gọn cùng phong cách.
- Giữ nguyên JSON, RUN, đồng hồ và các chức năng đo/lọc/lưu.

Trong SETTINGS, bấm ↻ để kiểm tra rồi chọn CẬP NHẬT.
