# DynoTest DATNL — Updates

Kênh cập nhật công khai chính thức. Source code giữ trong repo riêng tư.

## Bản hiện tại: ver1.1.71

Trạng thái Dyno chỉ hiển thị ĐANG KẾT NỐI / ĐÃ KẾT NỐI / NGẮT KẾT NỐI, bỏ mã 4001/1002/AUTH và chi tiết lỗi kỹ thuật khỏi nhãn/splash. Tự thử kết nối lại giữ chart đang mở và active, đồng bộ BIT4 ON khi có status hợp lệ. Ngắt chủ động giữ cách đóng chart như trước. Giữ màu vàng/xanh/đỏ, COM/baud và toàn bộ luồng đo/dữ liệu từ v170.

Bản phát hành đã qua kiểm tra Windows, quét Defender cho ứng dụng và bộ cập nhật, kiểm tra giữ JSON/RUN và khởi động lại.

Trong SETTINGS, bấm ↻ để kiểm tra rồi chọn CẬP NHẬT.
